# Contact Book

## Project Overview
A Python-based Contact Book application that allows users to manage contact information through a command-line interface and a graphical user interface (GUI).

## Technologies Used
- Python
- Tkinter for the graphical user interface
- JSON for storing contact information

## Features
- Add new contacts
- Search for existing contacts
- Update contact details
- Delete contacts
- Validate phone numbers
- Store contact data in a JSON file

## Project Structure
- `contact_book.py` — command-line application
- `contact_gui.py` — graphical user interface
- `contacts.json` — contact data storage

## Setup Instructions

### Prerequisites
Install Python 3.x on your computer.

### Run the Application
Clone or download this repository and open a terminal in the project folder.

To run the command-line application:

```bash
python contact_book.py
```

To launch the graphical interface:

```bash
python contact_gui.py
```

No additional third-party packages are required if you use a standard Python installation with Tkinter available.
